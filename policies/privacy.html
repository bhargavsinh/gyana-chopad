ગોપનીયતા નીતિ

Privacy Policy · Gyāna Chopad V1.4

અમે કયો ડેટા એકત્રિત કરતા નથી અને સ્થાનિક રમત કેવી રીતે કાર્ય કરે છે.

૧. પરિચય

Gyāna Chopad એક static web application છે જે GitHub Pages પર હોસ્ટ થાય છે. રમત તમારા બ્રાઉઝરમાં ચાલે છે. આ નીતિ સમજાવે છે કે અમે કયો ડેટા એકત્રિત કરતા નથી, અને રમત દરમિયાન શું ફક્ત તમારા ઉપકરણ પર રહે છે.

૨. અમે શું એકત્રિત કરતા નથી

  • નામ, ઇમેઇલ, ફોન નંબર અથવા સરનામું — કોઈ નોંધણી ફોર્મ નથી
  • લૉગિન / એકાઉન્ટ / પાસવર્ડ
  • ચુકવણી અથવા બિલિંગ માહિતી
  • સ્થાન (GPS) — રમત સ્થાન માંગતી નથી
  • જાહેરાત અથવા વર્તણૂકીય ટ્રેકિંગ માટે તૃતીય-પક્ષ analytics — રમત કોડમાં નથી
  • કેમેરા, માઇક્રોફોન અથવા સંપર્કોની ઍક્સેસ
ખેલાડી નામો: જે નામ તમે દાખલ કરો છો તે માત્ર તમારા બ્રાઉઝરની મેમરીમાં રમત સત્ર દરમિયાન રહે છે. પેજ બંધ અથવા રિફ્રેશ થતાં તે સાફ થઈ જાય છે (જ્યાં સુધી ભવિષ્યમાં સ્પષ્ટ localStorage વિકલ્પ ઉમેરવામાં ન આવે).

૩. સ્થાનિક (device-side) ડેટા

રમતની સ્થિતિ — ટોકન સ્થાન, વારો, પાસાની કિંમત, મોડ — JavaScript મેમરીમાં રહે છે. આ ડેટા અમારા સર્વર પર મોકલાતો નથી, કારણ કે રમત માટે કોઈ એપ્લિકેશન સર્વર નથી.

૪. હોસ્ટિંગ અને લોગ્સ

સાઇટ GitHub Pages દ્વારા પીરસાય છે. હોસ્ટિંગ પ્લેટફોર્મ તકનીકી લોગ્સ (IP, user-agent, વિનંતી સમય) રાખી શકે છે — તે GitHub ની નીતિઓ અનુસાર છે, આ રમતના કોડ દ્વારા નિયંત્રિત નથી.

૫. તૃતીય-પક્ષ સંસાધનો

  • Tailwind CSS CDN — સ્ટાઇલ માટે
  • Google Fonts — નોટો સાન્સ ગુજરાતી / ડિસ્પ્લે ફોન્ટ

આ સેવાઓ તમારા બ્રાઉઝરથી સીધી લોડ થાય છે. તેમની પોતાની privacy practices લાગુ પડે છે.

૬. બાળકો

રમત શૈક્ષણિક છે અને પારિવારિક ઉપયોગ માટે યોગ્ય ગણાય. અમે જાણીને ૧૩ વર્ષથી નાના બાળકોની વ્યક્તિગત માહિતી એકત્રિત કરતા નથી — કારણ કે અમે કોઈ personal data એકત્રિત જ કરતા નથી. નાના બાળકો સાથે વયસ્કની હાજરી યોગ્ય છે. પારિવારિક ઉપયોગ જુઓ.
