સુરક્ષા નીતિ

Security Policy · Gyāna Chopad V1.4

Static site માટે વાસ્તવિક સુરક્ષા નિયંત્રણો — માર્કેટિંગ નહીં.

૧. વાસ્તવિકતા સાથે શરૂઆત

Gyāna Chopad એક static, client-only શૈક્ષણિક રમત છે. કોઈ યુઝર એકાઉન્ટ, કોઈ API backend, કોઈ ચુકવણી સિસ્ટમ નથી. તેથી “enterprise security product” જેવા દાવા અહીં લાગુ પડતા નથી. આ પૃષ્ઠ ખરેખર શું કરવામાં આવ્યું છે તે જણાવે છે.

સિદ્ધાંત: જે ડેટા એકત્રિત જ નથી થતો, તે લીક થઈ શકતો નથી. સૌથી મજબૂત privacy control ઘણી વાર minimal data collection હોય છે.

૨. અમલમાં મૂકાયેલા નિયંત્રણો

૨.૧ Client-side input safety

  • ખેલાડી નામો js/security.js દ્વારા sanitize થાય છે
  • HTML/script અક્ષરો દૂર; લંબાઈ મર્યાદા (૨૦ અક્ષર)
  • નામો UIમાં text તરીકે રજૂ — arbitrary HTML તરીકે નહીં

૨.૨ Content Security Policy (CSP)

મુખ્ય પેજ અને policy પૃષ્ઠો પર CSP meta ટેગ છે. હેતુ: અનધિકૃત script/style સ્ત્રોતો મર્યાદિત કરવા.

૨.૩ અન્ય

  • referrer policy: no-referrer
  • Relative paths — deployment portable
  • કોઈ form POST / remote game API નથી
  • .well-known/security.txt — સુરક્ષા સંપર્ક માર્ગ

૩. શું “Ultra security” નથી

  • કોઈ penetration-test certificate અથવા SOC2 દાવો નથી
  • કોઈ end-to-end encryption of “accounts” — accounts જ નથી
  • CDN અને fonts તૃતીય-પક્ષ છે
  • GitHub Pages પ્લેટફોર્મ-level controls અલગ છે

૪. જવાબદાર વપરાશકર્તા વર્તન

  • અજાણ્યા forks પર personal data ન નાખો
  • જો તમે fork કરો તો CSP અને sanitize જાળવો
  • સંવેદનશીલ માહિતી ખેલાડી નામમાં ન લખો

૫. સમસ્યા રિપોર્ટ

સુરક્ષા સંબંધિત મુદ્દા માટે GitHub repository પર issue ખોલો, અથવા .well-known/security.txt માં જણાવેલ માર્ગ અનુસરો.
