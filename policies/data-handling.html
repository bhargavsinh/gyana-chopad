ડેટા હેન્ડલિંગ

રમતમાં ડેટા કેવી રીતે વહે છે — સર્વર વિના.

૧. ડેટા પ્રવાહ

રમતનો તમામ તર્ક બ્રાઉઝરમાં ચાલે છે. JSON ફાઇલો static assets છે. ખેલાડી નામો પાછા સર્વર પર મોકલાતા નથી.

[તમારું ઉપકરણ] → HTML/JS/JSON લોડ (GitHub Pages)
                → રમત મેમરીમાં ચાલે
                → કોઈ game-state upload નથી

૨. પ્રક્રિયા કરાતો ડેટા

  • ખેલાડી નામો (session, sanitized)
  • પાસા અને સ્થાન (session)
  • મોડ અને exact-win વિકલ્પ (session)

૩. સંગ્રહ સમયગાળો

મૂળભૂત રીતે: ટૅબ/વિન્ડો બંધ થતાં સત્ર સમાપ્ત. કોઈ સર્વર-સાઇડ retention નથી.

૪. શેરિંગ

રમત તમારો game state તૃતીય પક્ષો સાથે શેર કરતી નથી. ગોપનીયતા જુઓ.
